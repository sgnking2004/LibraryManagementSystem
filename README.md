# Hibernate CRUD Project

## Overview
A Java-based application demonstrating database operations using Hibernate ORM and Maven.

## Technologies Used
- Java
- Hibernate ORM
- Maven
- MariaDB / MySQL
- IntelliJ IDEA

## Features
- Create records
- Read and display records
- Update existing records
- Delete records

## Prerequisites
- JDK
- Maven
- XAMPP with MariaDB/MySQL
- IntelliJ IDEA

## Setup
1. Clone this repository.
2. Create the required database in MariaDB/MySQL.
3. Configure your database connection using your local credentials.
4. Build the project using Maven.
5. Run the main application class.
